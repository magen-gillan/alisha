# مفاتيح مزودي النماذج

تقرأ Alisha مفاتيح المزودين من متغيرات بيئة الخادم فقط؛ لا تُرسل المفاتيح إلى المتصفح، ولا تُخزَّن في إعدادات Zustand أو `localStorage`. تعرض صفحة «المفاتيح» حالة الاتصال وقائمة النماذج المتاحة، وتحفظ اختيار المزود والنموذج فقط على جهاز الزائر.

## متغيرات البيئة المدعومة

- Google Gemini: `GEMINI_API_KEY`، `GEMINI_API_KEY_2`
- OpenAI: `OPENAI_API_KEY`
- OpenRouter: `OPENROUTER_API_KEY`، `OPENROUTER_API_KEY_2`
- Hugging Face: `HUGGINGFACE_API_KEY` أو `HF_TOKEN`
- Z.ai / GLM: `ZAI_API_KEY` أو `GLM_API_KEY`
- Pollinations: `POLLINATIONS_API_KEY` اختياري؛ يتوفر مسار مجهول الهوية عندما تسمح الخدمة بذلك

أضف القيم في إعدادات بيئة Vercel (Production، وأي بيئات أخرى مطلوبة) أو مدير أسرار الخادم. لا تضعها في مستودع Git، ولا تستخدم بادئة `NEXT_PUBLIC_`، ولا تلصقها في واجهة الموقع. ملف `.env.example` يسرد الأسماء فقط ولا يحتوي أسرارًا.

## سلوك صفحة المفاتيح

عند فحص مزود، يطلب الخادم كتالوج النماذج من نقطة القراءة الخاصة به، ويعيد للواجهة حالة عامة وعدد النماذج. لا يعيد الاستجابة أي قيمة مفتاح أو رسالة خطأ خام من المزود. يختار المستخدم المزود ثم نموذجًا من الكتالوج المعاد، ويُرسل الاختيار فقط مع المحادثة. فحص المفتاح يستعلم قائمة النماذج للقراءة فقط ولا يرسل طلب توليد.

## ملاحظة تشغيلية للموقع العام

لأن زوار الموقع يستخدمون مفاتيح الخادم المشتركة، ضع حدود استخدام وإنفاق على حسابات المزودين. يطبق مسار الدردشة حدًا مبدئيًا لكل عنوان IP وحدودًا لطول المحادثة والإجابة، لكن حد الذاكرة داخل خادم التطبيق وحده ليس عدّادًا عالميًا ثابتًا بين جميع مثيلات Vercel. لحماية أقوى على الإنتاج، أضف rate limiter مشتركًا (مثل Redis/Upstash أو Vercel Firewall) و/أو CAPTCHA قبل زيادة الحصة العامة.
